# Frontend — PIPREVENDA-1680

Você está trabalhando no frontend React/Next.js. Antes de criar página,
componente ou hook de dados, consulte
`.claude/skills/arquitetura-frontend-nextjs/SKILL.md` (raiz do repo).

Resumo: App Router por entregável (`/contratos`, `/performance`,
`/reappraise`, `/juridico`, `/book`), tipos gerados via OpenAPI, CSR para
telas de dados/listagem paginada, SSR só no shell/autenticação, React Query
para data-fetching.

Este repositório ainda não tem código de produto — ao criar o primeiro app,
seguir esta estrutura e não inventar uma nova.
